# Reconstruction rules

The rock is rebuilt in the digital world first, as a record of where it began. This uses [rock-remaker](https://github.com/Kyruaaaa/rock-remaker), which turns six photos into a Blender model.

## The photos

1. Photograph the rock **before** it goes outside.
2. Take six views: front, right, back, left, top, bottom.
3. Use a white background.
4. Front is the side that will face the window.
5. Keep the distance and light the same for all six.

## The model

1. Name the sheet with the rock's ID, for example `2026-11-05_basalt`.
2. Build the model with rock-remaker.
3. Don't repair or smooth it. The model keeps what the photos saw.
4. Save it. This model never changes after this step.

## Why

Every other step changes the rock. This one is the only record of it before the day happened.
